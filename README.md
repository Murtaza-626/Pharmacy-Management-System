# Pharmacy Management System - Frontend

The Pharmacy Management System is a full-stack web application designed to help pharmacies manage their daily operations digitally. This repository contains the frontend implementation built using React and Tailwind CSS. The system allows authorized users to manage medicine inventory, track available stock, record sales, and monitor pharmacy performance through an interactive dashboard.

---

## Key Features

- **User Authentication:** Secure login and registration interfaces for authorized users.
- **Admin Dashboard:** Overview of total medicines, total sales, available stock, and real-time low-stock alerts.
- **Medicine Inventory Management:** Full CRUD functionality to add, view, update, and delete medicine records (including name, category, manufacturer, price, stock quantity, and expiry date).
- **Sales Management:** Point-of-sale interface to search items, create customer bills, calculate grand totals, and process checkouts.
- **Responsive User Interface:** Clean, modern, and user-friendly interface built with Tailwind CSS that works seamlessly across different screen sizes.

---

## Tech Stack

- **Framework:** React.js
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM

## Getting Started

Follow these steps to set up and run the frontend application on your local machine.

### Prerequisites

Ensure you have **Node.js** and **npm** installed on your system.

### Installation & Setup

1. Open your terminal and navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```

2. Install all required dependencies:
   ```bash
   npm install
   ```

3. Start the React development server:
   ```bash
   npm start
   ```

4. Open your browser and go to `http://localhost:3000` to access the application.
